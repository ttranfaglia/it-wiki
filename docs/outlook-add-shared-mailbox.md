# Add a Shared Mailbox to Outlook

*Last updated: 10/5/2026 · Applies to: Outlook (classic and new) and Outlook on the web · Office 365 / Microsoft 365*

A shared mailbox is an inbox that several people use, for example **info@napacoe.org** or a department address. Everyone with access can read and send from it, so there is no shared password to pass around.

## Before you start

- You must have been given access to the shared mailbox. If you haven't, [submit a Zendesk ticket](https://napacoe.zendesk.com/) and include the mailbox name, and ask for **Full Access** and **Send As** (so you can send as the shared address).
- After access is granted, wait up to **60 minutes**. The mailbox often appears in Outlook on its own during that time.
- You do **not** need a separate password for the shared mailbox. You sign in as yourself.

## Check first: it may already be there

In Outlook, look at the folder list on the left. A shared mailbox with Full Access is often added automatically under your own mailbox (this is called *automapping*). If you can see it, you're done.

## Outlook on the web (office.com)

This works on any computer and is the quickest check.

1. Go to **office.com** and open **Outlook**.
2. In the folder pane on the left, right-click **Folders** and select **Add shared folder or mailbox**.
3. Type the shared mailbox address (for example, **info@napacoe.org**) and select it.
4. Select **Add**. The mailbox appears in your folder list.

## New Outlook for Windows and Mac

1. In the folder pane, right-click your account name (your email address).
2. Select **Add shared folder or mailbox**.
3. Enter the shared mailbox address and select **Add**.
4. It appears in your folder list. Select it to open.

## Classic Outlook for Windows

1. Select **File**, then **Account Settings**, then **Account Settings** again.
2. Select your account and choose **Change**, then **More Settings**.
3. Open the **Advanced** tab and select **Add** under **Open these additional mailboxes**.
4. Type the shared mailbox name or address, select **OK**, then **Apply** and **OK**.
5. Select **Next**, then **Finish**, then close the window. Restart Outlook.

## Outlook on Mac (classic)

1. Select **Outlook**, then **Settings**, then **Accounts**.
2. Select your account, then **Delegates and Sharing** (or **Advanced**), then **Shared with me** / **Open additional mailbox**.
3. Enter the shared mailbox address and add it. Restart Outlook.

## Send email from the shared mailbox

You must have **Send As** (or **Send on Behalf**) permission.

1. Start a new email.
2. If you don't see the **From** line, select **Options**, then **Show From**.
3. Select **From**, then **Other email address** (or type it) and enter the shared mailbox address.
4. Write your message and send it. Replies go to the shared mailbox, not to your own.

> **Tip:** When you reply to a message that arrives in the shared mailbox, Outlook usually picks the shared address in **From** automatically. Always check the **From** line before you send.

## Where do sent messages go?

By default, a copy of what you send from the shared address goes to the **Sent Items** of the shared mailbox, so your teammates can see it. Your administrator may change this.

## Troubleshooting

| Problem | Try this |
|---|---|
| The shared mailbox isn't in my list | Check that you have access, wait up to 60 minutes, then restart Outlook. Try Outlook on the web first. |
| "You don't have permission" or "Can't open" | You don't have Full Access yet. [Submit a Zendesk ticket](https://napacoe.zendesk.com/) with the mailbox name. |
| I can read but not send | You need **Send As** permission. Ask in the same ticket. |
| The mailbox is there but empty | Select it and let it sync. Check you're looking at the right folder, such as **Inbox**. |
| Two copies of the mailbox | Remove the manually added one: right-click it and choose **Remove shared folder**, then restart. |
| Messages sent "on behalf of" instead of "from" | You have **Send on Behalf** instead of **Send As**. Ask for **Send As** if that's what you need. |
| Shared mailbox is slow or too big | Don't download everything for offline use. In classic Outlook, it can help to turn off **Download shared folders**. Ask us if unsure. |

## Remove a shared mailbox from your Outlook

- **Outlook on the web / new Outlook:** Right-click the shared mailbox in the folder list and choose **Remove shared folder** or **Remove**.
- **Classic Outlook:** Go to the same **More Settings > Advanced** screen, select the mailbox and choose **Remove**.

Removing it from Outlook does not delete the mailbox or its messages.

## Good habits

- Check the **From** line each time you send.
- Don't forward shared-mailbox mail to your personal email.
- Tell your team how to share work, for example by using categories or a follow-up flag, so two people don't answer the same message.
