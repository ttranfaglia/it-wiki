# Sync OneDrive to Your Computer

*Last updated: 10/5/2026 · Applies to: Windows and Mac · Office 365 / Microsoft 365*

OneDrive keeps your files safe in the cloud and, when you turn on sync, shows them in a folder on your computer. Edit a file on your computer and the change appears everywhere else, including on your phone and at office.com. 

## What you need

- Your work or school account (for example, **username@napacoe.org**)
- An internet connection
- About 5 minutes 

## Set up OneDrive on your computer

### Windows 

OneDrive is already installed on most Windows computers.

1. Select **Start** and type **OneDrive**, then open it.
2. Enter your work or school email and select **Sign in**.
3. Enter your password and approve the MFA prompt on your phone.
4. When it asks where your OneDrive folder will be, keep the default location and select **Next**.
5. Follow the prompts. When you see your folder in File Explorer, you're done.

Your files appear in **File Explorer** under **OneDrive - [My Files]**.

### Mac

1. Open **OneDrive** from Applications. If you don't see it, ask us to install it (see Still stuck? below).
2. Sign in with your work or school account and approve the MFA prompt.
3. Choose your OneDrive folder location and follow the prompts.

## What the icons mean

Look at the OneDrive cloud icon near the clock (Windows: bottom right; Mac: top menu bar), and at the icons next to each file.

| Icon | Meaning |
|---|---|
| Blue cloud next to a file | The file is online only. It uses no space on your computer and downloads when you open it. |
| Green circle with a check | The file is on your computer. |
| Solid green circle with a check | You marked it **Always keep on this device**. |
| Blue circling arrows | Syncing now. Wait for it to finish. |
| Red circle with an X | There is a sync problem. Select the cloud icon to see which file and why. |
| Gray cloud / line through the cloud | You are signed out or sync is paused. |

## Choose what stays on your computer (Files On-Demand)

- **Free up space:** Right-click a file or folder, then choose **Free up space**. The file stays online.
- **Keep it available offline:** Right-click and choose **Always keep on this device**. Do this for files you need without internet.

## Back up Desktop, Documents and Pictures

If Desktop, Documents and Pictures are backed up, a lost or broken computer won't lose your files.

1. Select the OneDrive cloud icon, then the **gear** icon, then **Settings**.
2. Open the **Sync and backup** tab and select **Manage backup**.
3. Turn on the folders you want to protect and select **Save changes**.

Your administrator may already do this for you. If the option is missing or gray, that's why.

## Sync a shared library or folder

If someone shares a folder or SharePoint library with you and you want it on your computer:

1. Open the shared folder in your web browser at office.com (**OneDrive** or **SharePoint**).
2. Select **Add shortcut to My files** (OneDrive) or **Sync** (SharePoint).
3. Wait a moment. It appears in File Explorer or Finder.

## Pause or resume sync

1. Select the OneDrive cloud icon.
2. Select the **gear** icon, then **Pause syncing** and choose a time.
3. To resume, select the cloud icon, then **Resume syncing**.

## Troubleshooting

| Problem | Try this |
|---|---|
| "Sync pending" or arrows that never stop | Wait a few minutes, then restart your computer. Large files take a while. |
| Red X on a file | Select the OneDrive icon and read the message. The file name may have unsupported characters such as `\ / : * ? " < > |`, or the file is open in another program. Close it, rename it and try again. |
| "Your OneDrive is full" | Delete files you no longer need, and empty the **Recycle bin** at office.com. Then check **Manage storage**. |
| Signed out or "Sign in to sync" | Select **Sign in**, enter your account and approve the MFA prompt. |
| Files missing from the folder | Check the online version at office.com. Someone may have moved or deleted them (see Restore below). |
| Path or file name too long | Move the file nearer the top of the folder or shorten the name. |
| Paused automatically | Your device is in battery saver or on a metered connection. Plug in or connect to Wi-Fi. |

### Restore a deleted file or an older version

1. Go to **office.com** and open **OneDrive**.
2. Select **Recycle bin** on the left, select the file and choose **Restore**.
3. For an earlier version of a file, right-click it, choose **Version history** and restore the version you want.

### Last resort: reset OneDrive

Resetting does not delete your files, but it re-syncs everything, which can take a while.

1. Press **Windows key + R**.
2. Paste `%localappdata%\Microsoft\OneDrive\onedrive.exe /reset` and press **Enter**.
3. Wait a minute. If OneDrive does not start again, open it from the Start menu.

## Good habits

- Save work in your OneDrive folder, not in random places on your computer.
- Check that the green check or cloud icon shows before you shut your laptop. Don't close it mid-sync.
- Don't sign in to OneDrive with a personal account on a work computer.
