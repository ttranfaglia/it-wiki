# Open and Read a PDF Without Adobe Acrobat

*Last updated: 10/6/2026 · Applies to: Windows and Mac · Google Chrome*

You do not need Adobe Acrobat to open, read, search or print a PDF. Google Chrome has a free PDF reader built in. This article shows you how to use it.

## What you need

- A PDF file (from email, a website or your OneDrive)
- Google Chrome
- About 2 minutes

## Open a PDF in Google Chrome (Windows and Mac)

Chrome opens PDFs by itself. No setup needed.

### From a file on your computer

1. Find the PDF in **File Explorer** (Windows) or **Finder** (Mac).
2. Right-click the file and choose **Open with**, then **Google Chrome**.
3. The PDF opens in a new Chrome tab.

You can also drag the PDF file into an open Chrome window.

### From an email in Outlook

1. Save the attachment to your computer first. Open the email, select the arrow next to the attachment and choose **Save as**.
2. Open the saved file with Chrome as described above.

### From a website

Select the PDF link. It opens in a Chrome tab. Select **Download** in the toolbar if you want a copy on your computer.

If a PDF downloads instead of opening, see **Troubleshooting** below.

## Make Chrome your default PDF reader (Windows)

Do this once, and every PDF you double-click will open in Chrome.

1. Right-click any PDF file and choose **Open with**, then **Choose another app**.
2. Select **Google Chrome**.
3. Turn on **Always use this app to open .pdf files**, then select **OK**.

If you don't see the option, or the setting won't change, your computer may be managed by IT. You can still use **Open with** each time.

## Read, search and move around

Use the toolbar at the top of the PDF.

| I want to | How |
|---|---|
| Zoom in or out | Select **Zoom in** or **Zoom out** in the toolbar, or hold **Ctrl** (**Cmd** on Mac) and scroll |
| Fit the page to the window | Select **Fit to page** or **Fit to width** |
| Find a word | Press **Ctrl + F** (**Cmd + F** on Mac) and type it |
| Jump to a page | Type the page number in the page box |
| Turn the page sideways | Select **Rotate** |
| Highlight important text | Select **Draw**, choose **Highlighter**, then drag over the text |
| Remove a highlight or drawing | Select **Eraser** in the Draw panel and click it |
| Print | Select **Print** in the toolbar |
| Save a copy | Select **Download** |

The names of the buttons can change slightly when Chrome updates. Hover over an icon to see what it does.

## Print or save a copy

1. Press **Ctrl + P** (**Cmd + P** on Mac).
2. Choose your printer, or choose **Save as PDF** under **Destination** to make a new PDF.
3. Select **Print** or **Save**.

## Troubleshooting

| Problem | Try this |
|---|---|
| The PDF downloads instead of opening | In Chrome, select the three dots (top right), then **Settings** > **Privacy and security** > **Site settings** > **Additional content settings** > **PDF documents**, and choose **Open PDFs in Chrome**. If it's grayed out, IT manages that setting. |
| The PDF opens in another app I don't want | Right-click the file, choose **Open with**, then **Google Chrome**. |
| A blank page or an error message | Save the file to your computer first, then open it from there. If it came from email, the preview pane may be the problem. |
| The PDF asks for a password | Only the sender can give you that password. Ask them. Do not type your work password. |
| Text looks tiny or blurry | Zoom in. If the PDF is a scan (a picture of a page), you can't select the text. |
| I can't select or copy the text | The PDF may be a scan, or the author may have turned off copying. |
| A tool is missing from the toolbar | Update Chrome: select the three dots, then **Help** > **About Google Chrome**, and restart when asked. |
| A form won't let me type in it | See **Fill Out and Sign a PDF Without Adobe**. |
| A website says "Download Adobe Reader" | You do not need it. Close the page and open the PDF in Chrome instead. |

## Staying safe with PDFs

- Only open PDFs from people you know and expect. A PDF can contain a malicious link.
- Don't upload work documents to free "PDF reader" or "PDF converter" websites, or install a PDF extension from the Chrome Web Store without asking us. Your file may be stored by a company outside our control. The tools described here run inside Chrome on your computer.
- If a PDF asks you to sign in to Microsoft or Google, **do not**. Report it to us instead.
