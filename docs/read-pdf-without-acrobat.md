# Open and Read a PDF Without Adobe Acrobat

*Last updated: 10/6/2026 · Applies to: Windows and Mac · Microsoft Edge, Chrome, Mac Preview*

You do not need Adobe Acrobat to open, read, search or print a PDF. Every work computer already has a free PDF reader built in. This article shows you how to use it.

## What you need

- A PDF file (from email, a website or your OneDrive)
- A web browser (Microsoft Edge is recommended) or a Mac
- About 2 minutes

## Open a PDF in Microsoft Edge (Windows and Mac)

Microsoft Edge opens PDFs by itself. No setup needed.

### From a file on your computer

1. Find the PDF in **File Explorer** (Windows) or **Finder** (Mac).
2. Right-click the file and choose **Open with**, then **Microsoft Edge**.
3. The PDF opens in a new Edge tab.

### From an email in Outlook

1. Open the email and double-click the PDF attachment, or select the arrow next to it and choose **Open**.
2. If you are asked which app to use, choose **Microsoft Edge**.

### From a website

Select the PDF link. It opens in the browser tab. Use the **Save** (disk) icon in the toolbar if you want a copy on your computer.

## Make Edge your default PDF reader (Windows)

Do this once, and every PDF you double-click will open in Edge.

1. Right-click any PDF file and choose **Open with**, then **Choose another app**.
2. Select **Microsoft Edge**.
3. Turn on **Always use this app to open .pdf files**, then select **OK**.

If you don't see the option, or the setting won't change, your computer may be managed by IT. You can still use **Open with** each time.

## Read, search and move around

Use the toolbar at the top of the PDF.

| I want to | How |
|---|---|
| Zoom in or out | Select **+** or **-** in the toolbar, or hold **Ctrl** (**Cmd** on Mac) and scroll |
| Find a word | Press **Ctrl + F** (**Cmd + F** on Mac) and type it |
| Jump to a page | Type the page number in the page box |
| Show two pages at once | Select **Page view** and choose **Two pages** |
| Fit the page to the window | Select **Fit to page** |
| Turn the page sideways | Select **Rotate** |
| Read it out loud | Select **Read aloud** |
| Highlight important text | Select **Highlight**, then drag over the text |
| Add a note | Select the text, then choose **Add comment** |

The names of the buttons can change slightly when Edge updates. Hover over an icon to see what it does.

## Open a PDF on a Mac with Preview

1. Double-click the PDF. It opens in **Preview** by default.
2. Use the sidebar (**View**, then **Thumbnails**) to move between pages.
3. Press **Cmd + F** to search.
4. Select **View**, then **Table of Contents** if the PDF has one.

## Print or save a copy

1. Press **Ctrl + P** (**Cmd + P** on Mac).
2. Choose your printer, or choose **Save as PDF** to make a new PDF.
3. Select **Print** or **Save**.

## Troubleshooting

| Problem | Try this |
|---|---|
| The PDF opens in another app I don't want | Right-click the file, choose **Open with**, then **Microsoft Edge**. |
| A blank page or an error message | Save the file to your computer first, then open it from there. If it came from email, the preview pane may be the problem. |
| The PDF asks for a password | Only the sender can give you that password. Ask them. Do not type your work password. |
| Text looks tiny or blurry | Zoom in. If the PDF is a scan (a picture of a page), you can't select the text. |
| I can't select or copy the text | The PDF may be a scan, or the author may have turned off copying. |
| A form won't let me type in it | See **Fill Out and Sign a PDF Without Adobe**. |
| A website says "Download Adobe Reader" | You do not need it. Close the page and open the PDF in Edge instead. |

## Staying safe with PDFs

- Only open PDFs from people you know and expect. A PDF can contain a malicious link.
- Don't upload work documents to free "PDF reader" or "PDF converter" websites. Your file may be stored by a company outside our control.
- If a PDF asks you to sign in to Microsoft, **do not**. Report it to us instead.
