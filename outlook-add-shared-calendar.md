# Add a Shared Calendar to Outlook

*Last updated: 10/5/2026 · Applies to: Outlook (classic and new) and Outlook on the web · Office 365 / Microsoft 365*

A shared calendar lets you see (and sometimes edit) another person's or a team's calendar, such as a department schedule, a room calendar or a coworker's availability. It appears next to your own calendar in Outlook.

## Before you start

- The calendar must be **shared with you**, either by its owner or by TTSS. If it isn't, ask the owner to share it (see [Share your own calendar](#share-your-own-calendar)), or [submit a Zendesk ticket](https://napacoe.zendesk.com/) with the calendar name.
- You'll see more or less depending on the permission you were given:

| Permission | What you can do |
|---|---|
| Can view when I'm busy | See only busy/free blocks, no details |
| Can view titles and locations | See event titles and locations |
| Can view all details | See everything on each event |
| Can edit | Add and change events |
| Delegate | Edit and respond to meeting requests on the owner's behalf |

## If you received a sharing invitation

The easiest way is to use the email invitation.

1. Open the email that says **[Name] shared a calendar with you**.
2. Select **Accept** (or **Add this calendar**).
3. The calendar appears under **Shared calendars** in your Calendar view.

If you can't find the invitation, check **Junk Email** and **Other**, or use the steps below.

## Outlook on the web (office.com)

1. Go to **office.com** and open **Outlook**, then select the **Calendar** icon on the left.
2. Select **Add calendar** in the left pane.
3. Choose **Add from directory**.
4. In the **Contact or Calendar** box, type the person's or calendar's name and select it from the list.
5. Select **Add**. The calendar appears under **People's calendars** (or **Shared calendars**).

## New Outlook (Windows and Mac)

1. Select **Calendar** in the left bar.
2. Select **Add calendar**, then **Add from directory**.
3. Search for the person or calendar name, select it and choose **Add**.
4. It appears in your calendar list. Check the box next to it to show or hide it.

## Classic Outlook for Windows

1. Select **Calendar** at the bottom or side of Outlook.
2. On the **Home** tab, select **Open Calendar**, then **From Address Book**.
3. Search for the person or calendar, select it, then choose **Calendar ->** and **OK**.
4. It appears under **Shared Calendars**. Check the box to show it.

## Outlook on Mac (classic)

1. Select **Calendar**.
2. On the **Organize** tab, choose **Open Shared Calendar**.
3. Enter the name of the person or calendar and select **Open**.

## Use it day to day

- **Show or hide:** Check or uncheck the calendar in the list to see it alone or alongside yours.
- **Side-by-side view:** Select the calendar, then **View** and **Overlay** (or **Split**) to compare schedules.
- **Colors:** Right-click the calendar and choose **Color** to tell calendars apart.
- **Schedule a meeting:** In **Scheduling Assistant** or **Find a time**, add the person to see when they're free.
- **Add an event to a shared calendar** (if you have edit permission): Select that calendar first, then choose **New event**. Check the calendar name on the event before you save.

## Share your own calendar

1. In Calendar, right-click your calendar in the left list and choose **Sharing and permissions** (or **Share** in the toolbar).
2. Select **Add people** and enter their name or email.
3. Choose their permission (for example, **Can view when I'm busy** or **Can edit**).
4. Select **Share**. They receive an invitation.

> Share only what people need. For most coworkers, **busy/free** or **titles and locations** is enough.

## Remove a shared calendar from your view

1. Right-click the shared calendar in the list.
2. Choose **Remove** (or **Remove calendar**).

This only removes it from your Outlook. It does not delete the calendar or its events for anyone else.

## Troubleshooting

| Problem | Try this |
|---|---|
| I can't find the person or calendar | Check the spelling, or ask the owner to share it with your email. Room and resource calendars must be shared by TTSS. |
| The invitation never arrived | Check **Junk Email**, then ask the owner to share it again. |
| I see "busy" only | You have the busy/free permission. Ask the owner for more detail permission if needed. |
| I can't add or change events | You have view-only permission. Ask the owner for **Can edit**. |
| The calendar disappeared | Check that it is checked in the list, then restart Outlook. If it's still missing, add it again. |
| It's showing in the web but not in classic Outlook | Close Outlook and reopen it, wait a few minutes to sync, or add it again. |
| Times look wrong | Check both your time zone and the owner's time zone in **Settings**. |
| Appointments show up twice | Remove the extra copy of the calendar and keep one. |

## Good habits

- Always check which calendar an event is on before you save it.
- Keep private events marked **Private** so others can only see busy time.
- Remove calendars you no longer need to keep your view tidy.
